# Spendova Logo Concepts

These are exploratory raster concepts generated with the built-in image generator. The selected direction should be rebuilt as a precise vector system before production use.

## 01 — Flowing S Path

One continuous ribbon represents money moving through income, spending, saving, and future plans. This is the simplest and most scalable direction.

## 02 — Balanced Money Orbit

Two curved streams represent money coming in and going out while remaining balanced and controlled. This feels friendly and dynamic.

## 03 — Nova Clarity Spark

An `S` surrounding a restrained spark expresses the `nova` portion of Spendova: a new, clearer view of money. This has the strongest name story.

## 04 — Secure Open Frame

An `S` inside an open protective frame emphasizes privacy, control, and trust. This is the most security-oriented direction.

## 05 — Modular Data Ribbon

Interlocking ribbons represent transactions, analytics, and planning resolving into one financial picture. This feels the most digital and product-led.

## Suggested evaluation criteria

- recognizable at 24–32 pixels;
- memorable when shown without the wordmark;
- not confused with an existing finance brand;
- works in one color;
- communicates clarity and movement without promising investment growth;
- feels appropriate for both daily expenses and long-term planning.

## Current design recommendation

Shortlist concepts `01` and `03`. Use `01` if simplicity and app-icon scalability matter most. Use `03` if a more distinctive story tied to the Spendova name matters most.
